# Shot QC Checklist

## Narrative
- [ ] Intended beat is delivered.
- [ ] Start/end action states are correct.
- [ ] No unintended story information appears.

## Character
- [ ] Identity matches canon.
- [ ] Physical features and wardrobe match.
- [ ] Expression/performance fits the beat.
- [ ] Hands, limbs and interactions are plausible.

## Spatial
- [ ] Architecture matches canonical environment.
- [ ] Character/prop positions make geographic sense.
- [ ] Entrances/exits and screen direction are correct.
- [ ] Vehicle position/orientation is continuous.
- [ ] Established 180° rule is preserved.

## Camera
- [ ] Placement/framing match shot spec.
- [ ] Only intended camera motion occurs.
- [ ] Perspective is plausible.
- [ ] No unexplained axis crossing.

## Temporal / Physical
- [ ] Weather/wetness remain continuous.
- [ ] Lighting remains continuous.
- [ ] Cloth, rain, reflections and moving objects behave plausibly.
- [ ] No morphing, teleportation, duplication or disappearance.

## Technical
- [ ] Required aspect ratio/resolution.
- [ ] No unacceptable flicker/warping.
- [ ] Start/end frame is usable for adjacent-shot continuity.
- [ ] Asset ID/version recorded.

## Decision
**APPROVE / REVISE / REJECT**
