# Contributing to JUNGLE GENERAL

This repository is a film-production control system.

## Before Changing Canon
Do not directly alter a LOCKED continuity fact simply because a new generation looks better. Document the proposed change and identify affected downstream shots/assets.

## Documentation
- Use stable IDs.
- Preserve actual source filenames.
- Link shots to scene and sequence.
- Separate observed generation behavior from assumptions.
- Mark uncertain information as TBD rather than inventing it.

## Assets
- Register production-critical assets.
- Keep candidates separate from approved/locked references.
- Avoid unnecessary duplicate large binaries.

## Commits
Prefer scoped messages:
- `story:`
- `continuity:`
- `shot:`
- `prompt:`
- `asset:`
- `qc:`
- `docs:`

## Approval
Only explicitly approved material should be marked APPROVED or LOCKED.
